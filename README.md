# Angola-Localiza-2.2
Plataforma móvel offline-first de endereçamento digital e logística de última milha para Angola. Combina Plus Codes para georreferenciação espacial, governança territorial (PRONPET) para emissão de endereços oficiais verificados (AO-HUA), e gestão de entregas com provas de campo seguras validadas por criptografia (ECDSA).
