# src/components

Componentes reutilizáveis. Tudo pensado para usar ao sol e com uma mão:
texto escuro em fundo branco, letra grande e botões com pelo menos 56 px.

| Ficheiro | O que tem |
| --- | --- |
| `tema.ts` | Cores e tamanhos. |
| `ui.tsx` | `Ecra`, `Titulo`, `Texto`, `Campo`, `Botao`, `Ligacao`, `Caixa`, `Cartao`, `Linha`, `EcraCarregamento`. |
| `Icone.tsx` | Ícones simples dos separadores (react-native-svg). |
| `nomes.ts` | Nomes em português dos separadores, cargos e operações; datas. |
| `BotaoSair.tsx` | "Sair" com o aviso dos trabalhos por enviar. |
| `CampoCodigo.tsx` | Caixa dos 6 dígitos do MFA. |
| `EmConstrucao.tsx` | Separador que ainda não existe. |
